# Ports of Call Browser Edition (Vue 3)

## Run
- `npm install`
- `npm run dev`
- `npm run build`

## How to play
1. Start a **New Game**.
2. In **Port Dashboard**, use Captain's Orders:
   - Repair / Refuel / Charter / Lay Up / Load
3. Use **Office** to create a contract, then confirm in **Voyage Summary**.
4. In **World Map**, use:
   - **STOP ACTION** or `Space` to pause/resume
   - speed slider or `-` / `+`
5. Random storm events may interrupt travel and require a choice.
6. On arrival, complete the **Docking Mini-Game** (Arrows/WASD).
7. Repeat voyages, trade cargo, and buy better ships in **Ship Broker**.

## Save/Load
The game autosaves to `localStorage` on key transitions. Use **Continue** from the start screen.
